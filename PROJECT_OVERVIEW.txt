│ QUICK START COMMANDS                                                        │
└─────────────────────────────────────────────────────────────────────────────┘

Start Infrastructure:
  $ cd FarmRentalPlatform
  $ docker-compose up -d

Build & Run Backend:
  $ cd backend
  $ mvn clean package -DskipTests
  $ mvn spring-boot:run

Run Frontend (http://localhost:5173):
  $ cd frontend
  $ npm install
  $ npm run dev

Run Admin Panel (http://localhost:5174):
  $ cd admin-panel
  $ npm install
  $ npm run dev

Run Mobile App:
  $ cd mobile-app
  $ npm install
  $ npm start

API Documentation:
  → http://localhost:8080/swagger-ui.html
  → http://localhost:8080/api/v1/farms
  → http://localhost:8080/api/v1/bookings/calculate-quote

Database Clients:
  → pgAdmin: http://localhost:5050
  → Adminer: http://localhost:8888
  → Kafdrop: http://localhost:9000
  → Elasticsearch: http://localhost:9200
